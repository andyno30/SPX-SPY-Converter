COMMON QUESTIONS

Before you integrate

Is this included in SpyConverter Pro?

No. API plans, keys, billing, and usage limits are separate from the existing SpyConverter Pro website subscription.

Can I use live market data now?

Paid data access is not yet enabled. The dashboard shows your activation status, and documentation examples are clearly identified as synthetic.

What happens if I reach my limit?

The API returns HTTP 429 with a Retry-After header. There are no automatic overage charges. You may request an upgrade from your dashboard.

What happens if the source stops updating?

The last successful snapshot is usable for up to 120 seconds from its source timestamp. After that, requests fail with HTTP 503. Customer requests never trigger a market-data fetch.

Can I resell the data or share a key?

No. Plans cover approved internal applications. Redistribution, resale, and sharing access outside your organization require separate written authorization and applicable data rights.
