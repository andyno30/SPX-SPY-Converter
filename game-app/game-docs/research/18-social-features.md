# Social features

Research pass: 2026-09-07. Coverage is partial; unknowns are intentional.

The brief identifies Friends, Messages, Gifts, Guild and Chat as UI candidates. Each service needs independent evidence before being described as fully historical. The archived official website has community/My Room content, which does not establish the exact in-game mail, guild or chat protocol. [Official snapshot](https://web.archive.org/web/20120120025341/http://kr.arpia.kids.yahoo.com/web/).

Future interfaces: private profiles, bilateral friendship state, mailboxes, direct messages, chat channels and guild membership. Social writes require authentication, blocking/rate limits and explicit visibility policies. No multiplayer or messaging implementation is claimed in this foundation.
