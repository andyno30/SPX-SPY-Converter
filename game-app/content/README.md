# Arpia content

`research/` is the catalog and evidence layer. It must not be treated as executable game content. Main mission numbers are complete; scripts, maps and numeric balance are not.

Future reviewed runtime definitions live in `missions/main`, `missions/free`, `maps`, `npcs`, `monsters`, `pets`, `spells`, `items`, `equipment`, `dialogue/public`, `localization`, `battles` and `mazes`. They use strict schemas and semantic IDs. Test fixtures live with engine tests and are explicitly RESTORATION material.
