# User interface

Research pass: 2026-09-07. Coverage is partial; unknowns are intentional.

The three user-mentioned reference screenshots were not attached to this session. Their descriptions remain user requirements, not measurements. [Reference analysis](ui/reference-analysis.md) records the actual archive inspection and its limits.

The future renderer uses a fixed logical canvas and uniform fit/letterboxing. Mission panel, minimap, world and bottom controls keep spatial relationships. Portrait dialogue and battle use scene overlays. No modern dashboard replaces the historical gameplay screen.

Original resolution, exact exploration HUD dimensions, labels, minimap controls, icon hitboxes, bitmap font and all hover/pressed states still need full-frame references. Accessibility belongs in the host/input adapter without turning each moving sprite into a DOM node.
